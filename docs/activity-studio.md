# Activity Studio

Activity Studio is Somnora's capacity-aware library for small real-world, creative, reflective, and restorative invitations. It gives Nora more useful range without turning suggestion into authority.

## What is implemented

The Studio is a primary Workbench destination with five families:

- Discover changes what enters the user's attention.
- Connect prepares optional human contact without sending a message.
- Create uses a small constraint to help the user begin.
- Reflect works privately with what is already present.
- Reset lowers demand and returns attention to the moment.

Each activity can offer alternate versions. The deterministic matcher considers available time, energy, movement, social bandwidth, normalized weather, and privacy. If the first version does not fit but another does, the Studio selects the lower-friction alternative and labels that adjustment. If no version fits every boundary, the activity is held and has no start control.

## Consent boundary

Opening the Studio, filtering, selecting a card, and inspecting alternate versions never start an activity. An interactive exercise opens only after a separate user click.

The Studio cannot message another person, schedule an event, purchase anything, share content, contact a device, or write an outcome to Nora memory. Three Beautiful Things returns to Home because its existing invitation, consent receipt, and device route already live there.

## Availability language

The interface separates four states:

- Interactive here means the current Workbench implements the exercise.
- Review on Home means the existing consent-based hero path owns the action.
- Existing Somnora continuity means the feature predates the Workbench and has no claimed live launch bridge here.
- Concept preview means the idea is visible for product breadth but has no start control or action dispatch.

This distinction prevents a broad catalog from becoming a false claim about shipped behavior.

## Private exercises

Six Line Story stores six bounded lines only in React component memory. The lines do not enter browser storage, the relay, Nora memory, logs, or analytics. Closing the dialog clears all six lines. Somnora does not grade the result.

Private Release opens the existing burn exercise. Its text remains temporary and is cleared before the completion animation. Reduced-motion users receive a quiet dissolve without flames or particles.

## Current data boundary

The default context is derived from the privacy-safe seeded profile and makes no network request. Context Sources can replace seeded weather after a one-time browser location request and can summarize a user-selected ICS file locally. Activity Studio applies the normalized weather and availability window only after the user selects **Use current context**.

Event options remain fictitious demo fixtures. Fitness and Nutrition remain disconnected. See `external-context-connectors.md` for the complete permission, source, freshness, failure, and retention boundaries.
